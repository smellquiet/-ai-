# AI 行业日报看板

> 单文件、零依赖的 AI 行业每日资讯速览看板。设计语言参照 **HeyRoute.ai** 的极光网格（aurora mesh gradient）风格：浅色冰蓝→奶油渐变画布、三团柔边光晕、SVG 分形噪点颗粒、玻璃拟态卡片，并带有光标跟随光晕、卡片 3D 倾斜与高光跟随等鼠标滑动效果。打开即看、双击即用、断网可运行；顶部带每秒跳动的实时本地时钟、深浅色主题切换与离线安全的「刷新」按钮。新闻数据**直接写死在页面内**（无需任何脚本或联网即可运行）。

**风格**：HeyRoute.ai 极光网格风（浅色画布 + 青蓝 `#2ea6d1` / 青绿 `#1be4d0` / 暖橙 `#ff9d00` 光晕 + 玻璃拟态）　|　**外部依赖**：0　|　**离线可用**：是　|　**文件数**：2（交付物）

## 一、项目功能介绍

**页面展示内容**

- **顶部导航栏**：左侧品牌「AI 行业日报」配正方形图标，右侧为**实时本地时钟**（日期 + 时:分:秒，每秒刷新）、**深浅色主题切换**按钮与**刷新**按钮。
- **HERO 浅色极光**：冰蓝→奶油对角渐变 + 三团柔边光晕（青蓝 / 青绿 / 暖橙），三个光球随鼠标轻微视差移动；等宽大写徽标 `DAILY AI BRIEF · 日期`、主标题「AI 行业日报」（青蓝→青绿渐变高亮）、副标题「5 分钟看懂今天 AI 圈发生了什么」，以及一行状态条（默认显示「离线缓存 · 数据更新于 …」，点击刷新后变为「已刷新视图 · 时间」）。HERO 高度经过压缩，首屏即可露出下方要闻。
- **今日重点摘要**：一段总览文字 + 三条**要点列表**（核心实体关键词高亮），概括当天 AI 圈最重要的事。
- **工具栏（搜索 + 分类筛选）**：新闻区顶部提供关键词搜索框与分类筛选按钮（全部 / 模型发布 / 行业动态），可组合过滤。
- **三条新闻卡片**：每条包含标题、简要描述、来源与时间元信息、重要程度标签、「阅读完成」按钮，以及底部来源域名；卡片主体可点击在新标签页打开原文。**阅读进度胶囊**与**清除已读**按钮置于卡片列表上方。
- **右侧趋势面板（深青蓝玻璃）**：今日热点 TOP 3 与 6 个趋势关键词标签，使用深青蓝半透明玻璃（`backdrop-filter` 磨砂），与浅色极光正文区形成层次对比；热点条目与关键词均可点击，直接作为搜索词筛选今日新闻。
- **更新时间标注**：页脚有一行「内容更新于 2026-09-16 · 数据来源：公开科技媒体报道」。

**视觉设计特点（参照 HeyRoute.ai 极光网格风格）**

- **极光网格渐变（aurora mesh gradient）**：整页背景为冰蓝→奶油对角渐变，叠加三团低饱和 `radial-gradient` 光晕（左上青蓝、右上青绿、右下暖橙），柔边融合、互不过界，干净通透。
- **SVG 分形噪点颗粒**：内联 `feTurbulence` 噪声做 `body::before` 噪点层（`opacity .42` + 微模糊 + 径向遮罩边缘淡出），消除色带、增加胶片颗粒质感。
- **玻璃拟态（glassmorphism）**：导航、摘要、新闻卡片均为半透明白磨砂玻璃；右侧趋势面板为深青蓝玻璃，形成层次对比。
- **cerulean 主色系**：主色青蓝 `#2ea6d1`、深青蓝 `#2584a7` 与青绿 `#1be4d0` 点缀，暖橙 `#ff9d00` 仅出现在光晕；高优先级标签/顶条用青蓝，中优先级用青绿。
- **圆润玻璃几何 + 大写等宽小标签**：卡片 18px、标签/徽章 8–9px、按钮胶囊形；分区标题与徽标使用等宽字体、大写、1.3px 字距作为「技术路标」。
- **鼠标滑动效果**（仅在精确指针桌面设备启用）：
  - **光标跟随光晕**：`body::after` 随鼠标实时移动，位于内容之下、不干扰阅读。
  - **卡片 3D 倾斜 + 高光跟随**：鼠标在卡片内移动时卡片按光标做 `perspective + rotateX/rotateY` 轻微倾斜，并有白色高光团跟手。
  - **HERO 光球视差**：三个模糊光球随鼠标做小幅平移，增加纵深。
  - 以上效果用 `requestAnimationFrame` 节流鼠标事件；`prefers-reduced-motion` 或触屏（`hover:none`）下自动关闭。
- **深浅色主题**：通过 `<html data-theme>` 切换 CSS 变量，浅色为极光风、深色为压暗版极光；首次访问跟随系统 `prefers-color-scheme`，之后以 `localStorage` 记忆用户选择。
- **卡片层级分明**：第 1 条整行最宽最醒目，第 2、3 条并列成两列；顶部 3px 青蓝/青绿条标示优先级。
- 全局 `max-width: 1200px`，在 16:9 宽屏下留白合理、不拥挤。

**交互能力**

- **实时本地时钟**：导航栏日期与时间每秒自动刷新，纯本地计算，离线可用。
- **刷新按钮（纯本地重渲染）**：数据已写死在页面内，点击「刷新」仅重新渲染当前视图并更新状态条时间戳，**零网络请求**，离线可用、不会跨域报错。
- **搜索 + 分类筛选**：在搜索框输入关键词实时过滤（匹配标题/描述/来源/分类）；分类按钮按「全部 / 模型发布 / 行业动态」过滤；两者可组合。
- **趋势点击筛选**：右侧趋势热点条目与关键词标签均可点击，点击后自动填入搜索框进行筛选。
- **阅读进度 + 清除已读**：卡片列表上方显示「已读 N / 3」进度胶囊；「清除已读」按钮带二次确认，一键清空本地阅读记录。
- **资讯点击跳转**：点击卡片主体（标题、描述、留白区域）即在**新标签页**打开该条新闻的真实源网页；右上角的对勾徽章与「阅读完成」按钮位于更高层级，不会误触跳转。
- 「阅读完成」按钮可切换为「已完成 ✓」，并在卡片右上角弹出对勾徽章，再次点击可撤销；状态写入 `localStorage`，刷新/关闭后重开自动恢复。
- 卡片悬停时玻璃阴影加深、边框高亮、标题转青蓝，并给出键盘 `:focus-visible` 焦点框。
- 小于 768px 时自动切换为移动端布局（单列、趋势面板下移）。

## 三、文件结构

```
作业一每日ai资讯/
├── index.html     # 单文件应用：HTML + 内嵌 CSS + 内嵌 JavaScript（含写死的 DASHBOARD 数据块）★交付物
└── README.md      # 本说明文档 ★交付物
```

- `index.html` 是**完全自包含的单文件应用**：所有样式写在 `<style>` 内，所有脚本写在 `<script>` 内，不引用任何外部字体、图片、CSS 框架或 JS 库。
- 全站**不加载任何外部资源**（无字体、图片、CSS 框架、JS 库、CDN 请求），断网可用。卡片上的 `href` 仅用于点击时跳转原文，不会被浏览器预先加载。
- 新闻数据写死在 `DASHBOARD` 对象中，无需任何外部脚本即可运行。

> **作业提交说明**：本作业只需提交 `index.html` 与 `README.md` 两个文件。在任意电脑（包括老师电脑）上**双击 `index.html`** 即可打开运行，无需安装任何环境、无需联网、无需启动服务器。页面已内置 `<meta name="description">` 与内联 SVG favicon，标签与分享更完整。

### 实时时钟的实现方式

- 页面用 `new Date()` 取本地时间，封装 `pad()` / `fmtDate()` / `fmtTime()` 补齐位数，渲染到导航栏 `#clockDate`（年-月-日）与 `#clockTime`（时:分:秒）。
- 通过 `setInterval(tick, 1000)` 每秒刷新一次，**完全本地计算，不访问任何网络**，因此离线、断网、双击打开均正常工作。

### 深浅色主题切换的实现方式

- `<html>` 元素带 `data-theme` 属性（`light` / `dark`），所有颜色来自 CSS 变量；`:root` 定义浅色变量，`[data-theme="dark"]` 覆盖为压暗版极光配色（`body` 背景同步切换为深色极光）。
- 首次加载读取 `localStorage` 的 `ai-daily-theme-v1`；若无记录则跟随系统 `prefers-color-scheme`（`matchMedia("(prefers-color-scheme: dark)")`）。
- 点击导航栏主题按钮即在浅/深之间切换，并写回 `localStorage`；写入用 `try/catch` 包裹，隐私模式下静默降级为「本次会话有效」。
- 玻璃卡片、趋势面板、焦点环等均在深色下做了对比度适配，确保可读。

### 搜索与分类筛选的实现方式

- 搜索框 `input` 事件实时读取 `searchInput.value`，与每张卡的标题/描述/分类/来源拼接字符串做 `indexOf` 包含匹配；分类按钮点击设置 `currentCat`（全部 / 具体分类）。
- `applyFilter()` 遍历卡片，按「关键词命中 且 分类匹配」决定 `card.style.display`（命中显示、否则隐藏），并同步空状态提示与分类按钮高亮态。
- 趋势热点条目与关键词标签设置了 `data-keyword`，点击后把该关键词填入搜索框并调用 `applyFilter()`（chip 再次点击取消选中）；隐藏卡片不影响其「已完成」状态，恢复显示后状态保留。

### 阅读进度与清除已读的实现方式

- 每次阅读切换、状态恢复、重渲染后调用 `updateProgress()`，统计 `.news-card.done` 数量并写入「已读 N / 3」进度胶囊。
- 「清除已读」按钮触发 `window.confirm` 二次确认；确认后清空 `localStorage` 的 `ai-daily-read-state-v1`、移除所有卡片 `done` 类与对勾、复原按钮文案并刷新进度。

### 刷新按钮的实现方式（纯本地，无联网）

- 点击「刷新」先给图标加旋转动画，随后调用 `rerender()` 从写死的 `DASHBOARD` 重新渲染整页（始终成功），并把状态条更新为「已刷新视图 · 当前时间」。
- 由于数据已写死在页面内，**不再发起任何网络请求**，因此双击 `file://` 打开或老师电脑上都不会出现跨域报错，离线完全可用。

### 跳转功能的实现方式

- 标题文字外层包裹 `<a class="card-link">`，携带 `target="_blank"` 与 `rel="noopener noreferrer"`（新标签页打开，并防止新页面通过 `window.opener` 反向操作原页面）。
- 通过 `.card-link::after { position:absolute; inset:0; z-index:2 }` 把这个链接的点击区域**撑满整张卡片**，因此点击标题、描述或卡片留白都会跳转。
- 「阅读完成」按钮 `z-index:3`，对勾徽章同样 `z-index:3` 且 `pointer-events:auto`（拦截点击，避免误触跳转），三重层级互不干扰。
- 每个链接都带 `aria-label="阅读新闻：{新闻标题}（媒体名，新标签页打开）"`，屏幕阅读器可准确播报。

### 鼠标滑动效果的实现方式

- 通过 `window.matchMedia("(hover:hover) and (pointer:fine)")` 判断是否为精确指针的桌面设备，再用 `(prefers-reduced-motion:reduce)` 判断是否需降级；任一不满足则完全不绑定鼠标效果。
- **光标跟随光晕**：全局 `mousemove`（被动监听）中把光标坐标写入根元素 CSS 变量 `--mx / --my`；`body::after` 用 `radial-gradient(circle at var(--mx) var(--my), …)` 渲染低透明度光晕，`position:fixed; z-index:0` 位于内容之下。
- **卡片 3D 倾斜 + 高光跟随**：`bindCardFX()` 为每张卡绑定 `mousemove`——按光标相对坐标计算 `rotateX/rotateY`（约 ±3.5°）并加 `translateY(-6px)`，写入 `card.style.transform`（`perspective(1100px)`）；同时写 `--cx/--cy` 使 `.news-card::before` 白色高光团跟手，移出时清空 `transform`。
- **HERO 光球视差**：三个 `.orb` 按光标相对屏幕中心偏移做小幅 `translate`（系数逐球递增）。
- 为性能，**所有 `mousemove` 通过 `requestAnimationFrame` 节流**（仅在一次动画帧内应用最新坐标），避免高频 reflow。

### 阅读状态本地保存的实现方式

- 每条卡片用渲染时生成的唯一 `data-id`（由标题 slug 化而来）作为键，互不干扰。
- 点击「阅读完成」时，把该 id 的布尔值写入 `localStorage` 的 `ai-daily-read-state-v1` 键，值为形如 `{"google-deepmind-...": true}` 的 JSON。
- 页面加载时先 `loadState()` 读取该 JSON，再遍历卡片恢复「已完成 ✓」文案与对勾徽章。
- 读写都包在 `try...catch` 中：浏览器隐私模式或存储被禁用时静默降级为「本次会话有效」，不影响页面其它功能。

## 六、后续可以扩展的功能建议

- **运行时自动刷新**：如需页面打开即最新，可改为前端 `fetch` 公开资讯 API（接口支持 CORS），代价是 `file://` 双击打开会受限、需起本地服务器。
- **历史归档**：按日期生成 `YYYY-MM-DD.html` 快照，形成日报合集。
- **卡片展开详情**：点击卡片展开完整正文、原文链接与相关报道时间线。
- **导出为图片**：一键将看板导出为 16:9 PNG，直接用作科技视频封面或动态配图。
- **国际化**：增加英文版文案切换。

## 七、技术说明

- 仅使用原生 **HTML + CSS + JavaScript**，无任何构建步骤。
- 布局使用 CSS Grid（新闻区网格实现卡片层级）与 Flexbox。
- 响应式通过 `@media (max-width: 768px)` 与 `@media (max-width: 1080px)` 媒体查询实现，桌面端样式不受影响。
- 图标与装饰全部使用 CSS 绘制或 Unicode 字符（如 `✓`、状态点），不依赖图标字体；favicon 为内联 SVG `data:`。
- 阅读状态使用原生 `localStorage`（键名 `ai-daily-read-state-v1`）持久化，无第三方状态库。
- 跳转区域采用「 stretched link 」模式（伪元素撑满卡片），保证语义上是真实 `<a>` 且整卡可点。
- 焦点样式统一使用 `:focus-visible`，鼠标点击不出现焦点框、键盘 Tab 时清晰可见。
